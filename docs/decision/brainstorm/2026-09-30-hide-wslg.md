# 同梱プロファイルで /mnt/wslg を隠す

## Context

WSL2（WSLg あり）の `/mnt/wslg/distro` は `/` と同じファイルシステムを別の場所にマウントしたもので、`/mnt/wslg/run/user/<uid>` は `/run/user/<uid>` と同じ tmpfs である。
`hide` はリンクを解決した実パスにだけ効くので、同梱のプロファイルで隠した `~/.ssh` やセッションの D-Bus が、`/mnt/wslg` 経由で隔離の中から見える。
同梱のプロファイルは WSL2 向けに書かれているのに `/mnt/wslg` を隠していない。
botti のセッションからの報告（2026-09-30）を受け、同梱のプロファイルの直しを決める。

事実（2026-09-30、この環境、kakoi 0.5.0、利用者の既定のプロファイル、エントリの数だけを数えた）: `findmnt` で `/mnt/wslg/distro` は `/dev/sdd ext4` で `/` と同じデバイスだった。隔離の中から、隠した `~/.ssh` は 0 件、`/mnt/wslg/distro$HOME/.ssh` は 10 件見えた。`~/.config/kakoi/secrets` も `/mnt/wslg/distro` 経由で 1 件見えた。`/mnt/wslg/run/user/1000/bus` のソケットが見えた。利用者がプロファイルの `hide` に `/mnt/wslg` を足すと、どれも見えなくなり、名前解決は壊れなかった（`/etc/resolv.conf` の指す先は `/mnt/wsl` で、`/mnt/wslg` とは別）。

Position: 照合を終え（指摘 0 件）、承認待ち。

## Agreements

- A1 同梱のプロファイル（`examples/profile/default.toml`）の `hide` に `/mnt/wslg` を足し、理由をコメントに書く。
  - why: 同梱のプロファイルが隠す `~/.ssh` などの認証情報の置き場、`/run/user` のセッションの D-Bus、表示の経路（X11、Wayland、PulseAudio のソケット）が、`/mnt/wslg` 経由で隔離の中から見える。隔離の中のエージェントに WSLg の GUI は要らない。
  - decided_by: 利用者（推奨を採用）
- A2 同じファイルシステムの別のマウントから隠した場所が見える一般の問題は、この直しに含めない。既知の隙間 4（bind mount やハードリンクによる別の経路は隠せない）が既にこれを述べているので、新しい既知の隙間は足さない。
  - why: 仕組みで塞ぐ（別のマウントも隠す、または警告する）かは、許可リスト方式（全部隠して見せるものを選ぶ形）の壁打ちで一緒に決める。今回は同梱のプロファイルの既知の入口を塞ぐだけにする。
  - decided_by: LLM（範囲の整理。仕組みで塞ぐ案は利用者に示し、許可リストの壁打ちで扱う方向を提案済み）

## Rejected

- A3 `/mnt/wsl` も隠す。
  - why: WSL2 の `/etc/resolv.conf` は `/mnt/wsl/resolv.conf` へのリンクで、隠すと名前解決が壊れる。
