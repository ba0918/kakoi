## 17. 版とリリース

### 版の典拠

版は`Cargo.toml`だけで管理する。リリースごとに`CHANGELOG.md`へ項目を追加し、版の先頭に`v`を付けたタグを打つ。

### 利用者に届けるもの

| 配布物 | 契約 |
|---|---|
| 実行ファイル | Linux x86_64向け、静的リンク |
| 書庫 | `kakoi-v<版>-x86_64-unknown-linux-musl.tar.gz` |
| 書庫の中身 | 実行ファイル1つを平置きで含む |
| チェックサム | 書庫名に`.sha256`を付けたファイルに、書庫のSHA-256を添える |

書庫名はインストーラが機種に合う配布物を選ぶための契約である。静的リンクを使い、ビルドした機械のlibcの版を利用者側の動作条件に持ち込まない。CIと配布物の作成手順は、この仕様の対象外である。

### 確認する結果

`--version`、`Cargo.toml`、タグの版が一致し、書庫だけを取得した利用者がビルド道具なしで起動できること。版をソースの別の場所でも独立に管理している状態は契約違反である。
