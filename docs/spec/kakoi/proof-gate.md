# 製品実装前の実証の完了条件

Status: Draft（合意A151に基づく。実証は未完了）

## 実装開始の条件

残る実機検証を実装計画の最初に置き、完了条件を満たすまで製品実装へ進まない。要求仕様を維持し、実証に合わせて保証を弱めない。

## 対象

1. IPv4/IPv6・TCP/UDPのホスト接続と動的公開。許可範囲、ループバック待受、番号競合、終了・再利用を含む。
2. 全通信経路の許可判定。直接中継の経路も含め、アプリが制限を解除・迂回できず、起動と復帰で全許可の瞬間を作らない。
3. 制御処理停止時の有限許可、新規通信と既存通信の区別、安全な遮断・終了・復帰。端末とシグナル、終了コードの合意も確認する。
4. 将来のマルチキャスト・ブロードキャスト対応の変更範囲。方式差替えの要否と規模を具体化し、初版で対象外とする条件を評価する。

## 依存と対応環境

pasta・nftablesは候補であり、採用確定ではない。標準パッケージから導入できるOS・版と依存版、TUN/TAPとuser namespace等の条件を記録する。導入容易性を採用条件に含める。host/noneへ追加依存を必須にしない。

## 残る設計の確定

ホストDNS対応構成、通信経路と監督の機構、TTLゼロの有限猶予、具体的なホスト情報の取得先を、要求と実測に基づき確定する。元の許可モデル・保証・利用条件を変える必要があれば利用者へ戻す。実証が通らなければ製品実装を停止し、方式と導入負担を再相談する。

詳細な試験条件と部分観測は[実証記録](../../decision/brainstorm/2026-09-16-kakoi-net-evidence.md)を参照する。部分確認だけを全体の合格へ繰り上げない。
