# DNS名の入力と照合

草案。実装前に[実証の完了条件](../proof-gate.md)を満たす必要がある。

DNS名を指定するときは、その名前だけを許可するか、配下の名前も許可するかを選ぶ。入力表記は次の規則で揃え、許可判定と名前解決に共通で使う。

## 名前の一致とワイルドカード

`example.com`と書くと、その名前だけを許可する。`*.example.com`と書くと、親自身を含めず、配下の名前を深さに関係なく許可する。

| 指定 | `example.com` | `api.example.com` | `v1.api.example.com` |
|---|---|---|---|
| `example.com` | 一致 | 不一致 | 不一致 |
| `*.example.com` | 不一致 | 一致 | 一致 |

親自身も配下も許可するなら、二つの指定をそれぞれ書く。
ワイルドカードに使えるのは、入力の先頭にある半角の`*.`だけ。
`api*.example.com`や`api.*.com`、全角の星を使う`＊.example.com`は入力エラーになる。
名前を変換するときも、全角の星を半角に直して受け付けることはない。

英字の大小文字は区別せず、末尾のドット1個は取り除いて比べる。
`API.Example.com`、`api.example.com`、`api.example.com.`は同じ指定になる。
末尾ドットを省略しても完成した名前として扱い、ホストの検索用ドメインを補わない。

## 日本語の名前と変換結果

日本語などの国際化ドメイン名も、そのまま入力できる。ワイルドカードがある場合は先頭の半角`*.`を分け、名前の部分を変換する。

変換には既存ライブラリのUTS #46の非移行処理を使う。例えば`ＥＸＡＭＰＬＥ.com`は`example.com`に揃うが、`ß`を`ss`へ置き換えることはない。変換や検証に失敗した名前は入力エラーになる。

変換後のASCII名は、許可判定と名前解決の両方で同じものを使う。実際に使う名前は計画表示で確認できる。名前を変換しても、IP・ポートの制限や内部IPの検査を省略することはない。
